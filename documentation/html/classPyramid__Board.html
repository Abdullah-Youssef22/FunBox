Pyramid_Board::Pyramid_Board ( )

Default constructor that initializes a 3x3 X-O board.

Default constructor for Pyramid_Board.

Initializes a 5x5 board with pyramid-shaped playable positions. The board has 9 valid positions arranged in a pyramid:

  • Top level (row 2): 1 position
  • Middle level (row 3): 3 positions
  • Bottom level (row 4): 5 positions

All non-playable positions are marked with '*', and playable positions are initialized with the blank symbol.

Note
Calls the base Board constructor with dimensions 5x5

void initPrintableLocations ( )
friend

Initializes the list of valid playable positions on the pyramid board.

Populates the Pyramid_Board::printable vector with all 9 valid positions that form the pyramid shape:

  • Row 2: position (2,2) - pyramid top
  • Row 3: positions (3,1), (3,2), (3,3) - pyramid middle
  • Row 4: positions (4,0), (4,1), (4,2), (4,3), (4,4) - pyramid base
Note
This function should be called once during board initialization
Modifies the static Pyramid_Board::printable vector
