Detailed Description

Represents the game board for the SUS game.

Inherits from Board and manages moves, scoring, and game state.

int SUS_Board::calculate_score ( char sym)

Calculates the score for a given symbol.

Checks all rows, columns, and diagonals for the "SUS" pattern. Only counts if the last move in the pattern belongs to the given symbol.
