◆ display_ultimate_board()

void Ultimate_UI::display_ultimate_board ( Ultimate_Board * board) const

Displays the complete ultimate board state.

Shows the meta-board followed by all 9 mini-boards arranged in a 3x3 grid. Each mini-board is displayed side-by-side with its neighbors, and the active board is marked. Winners for each mini-board are shown below.

Parameters
boardPointer to the Ultimate_Board to display
Note
This provides a comprehensive view of the entire game state
Active mini-board is marked with "*ACTIVE*"
Mini-board winners are displayed below each board

Gets a move from the player (human or computer)

For human players, displays which mini-board is active and prompts for global position input. For computer players, generates random valid positions within playable mini-boards.

Parameters
playerPointer to the Player object making the move
Returns
Move<char>* Pointer to newly created Move object containing the player's move
Note
Human input: global row and column (0-8)
Computer moves are randomly generated within playable mini-boards
Displays active board information with color coding (RED for required, GREEN for open)
Warning
Caller is responsible for deallocating the returned Move object
