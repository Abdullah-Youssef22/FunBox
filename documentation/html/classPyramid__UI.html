Parameters

A pointer to a new Move<char> object representing the player's action.

For human players, prompts for position input via console and validates that the position is within the pyramid's playable area. For computer players, generates random valid positions within the pyramid.

Parameters
playerPointer to the Player object making the move
Returns
Move<char>* Pointer to newly created Move object containing the player's move
Note
Human input is validated to ensure it's within the pyramid shape
Invalid moves trigger error messages and re-prompt the user
Computer moves are automatically validated before being returned
