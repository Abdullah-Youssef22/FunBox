\doxysubsection{Detailed Description}
Represents the board for the Numerical Tic Tac Toe game. 

The board is a 3x3 grid where players place numbers (1–9). \doxylink{classPlayer}{Player} 1 uses odd numbers, \doxylink{classPlayer}{Player} 2 uses even numbers. A player wins if any row, column, or diagonal sums to 15.
