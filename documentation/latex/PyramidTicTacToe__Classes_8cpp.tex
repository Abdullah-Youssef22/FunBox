\doxysubsection{Detailed Description}
Implementation of Pyramid Tic-\/\+Tac-\/\+Toe game classes. 

\begin{DoxyAuthor}{Author}
Ammen
\end{DoxyAuthor}
This file contains the implementation of the Pyramid Tic-\/\+Tac-\/\+Toe game, which uses a pyramid-\/shaped board instead of the traditional 3x3 grid. The board has 9 playable positions arranged in a pyramid formation.

Populates the Pyramid\+\_\+\+Board\+::printable vector with all 9 valid positions that form the pyramid shape\+:
\begin{DoxyItemize}

\item Row 3\+: positions (3,1), (3,2), (3,3) -\/ pyramid middle
