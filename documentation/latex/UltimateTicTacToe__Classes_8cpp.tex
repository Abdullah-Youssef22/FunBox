\doxysubsection{Detailed Description}
Implementation of Ultimate Tic-\/\+Tac-\/\+Toe game classes. 

This file contains the implementation of Ultimate Tic-\/\+Tac-\/\+Toe, a complex variant where players compete on a 9x9 board divided into 9 mini-\/boards (3x3 each). Winning a mini-\/board claims that square on the meta-\/board. The objective is to win three mini-\/boards in a row on the meta-\/board.
