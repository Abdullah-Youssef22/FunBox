Default constructor that initializes a 3x3 X-\/O board. 

Default constructor for \doxylink{classPyramid__Board}{Pyramid\+\_\+\+Board}.

Initializes a 5x5 board with pyramid-\/shaped playable positions. The board has 9 valid positions arranged in a pyramid\+:
\begin{DoxyItemize}
\item Top level (row 2)\+: 1 position
\item Middle level (row 3)\+: 3 positions
\item Bottom level (row 4)\+: 5 positions
\end{DoxyItemize}

All non-\/playable positions are marked with \textquotesingle{}\texorpdfstring{$\ast$}{*}\textquotesingle{}, and playable positions are initialized with the blank symbol.

\begin{DoxyNote}{Note}
Calls the base \doxylink{classBoard}{Board} constructor with dimensions 5x5 
\end{DoxyNote}
